@frontierjs/basecamp

Ship your code to your own servers

A pushed repo goes in; a built release running live on your servers comes out, for the team that runs them.

  • The code in the repo is the source of truth; every release is built from it.
  • A build can fail or be cancelled, and then nothing goes live.
  • The line ends at a live site; backups and monitoring keep it safe and watched.
