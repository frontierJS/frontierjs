# Workbench -- layout

The file-by-file map. `CLAUDE.md` keeps the owners and the traps. Paths under
`api/src/` and `web/src/` match Basecamp's, because the wing moves in unchanged.

| Path | What |
| --- | --- |
| `db/schema.lite` | Member · Session (Haven's door) · ClaudeTranscript · ClaudeMessage · ClaudeWrite; no tenancy, no audit database |
| `db/migrations/main/` | generated by `bun run db:migrate`; nothing has shipped, so no upgrade step |
| `db/schema.d.ts` | generated by `bun run db:types` |
| `api/index.ts` | starts the app on `PORT`, else 5501 (`GLOBAL.workbench`) |
| `api/src/app.ts` | builds the app, never starts it; claims `app.own('workbench', ...)` |
| `api/src/workbench.types.ts` | types the claim by augmenting junction's exported `App` interface |
| `api/src/core/env.ts` | the environment: `WORKBENCH_KEY`, `ENCRYPTION_KEY`, `WORKBENCH_DIR`, `CLAUDE_BIN`, `HOST`, `BASECAMP` (the name of an entry in `basecamps.json`). No `LOCAL_MACHINE` -- this app IS the local machine |
| `api/src/core/workbench.ts` | `createWorkbench` -- the pins' directory and the Claude binary |
| `api/src/auth.ts` · `login.ts` · `principal.ts` | the door: mint a Session, read a token back to its member, `/door/*` routes, the per-call principal |
| `api/src/peer.ts` | this machine's peer key pair, minted into `~/.config/workbench/peer.json`, and `GET /door/peer` that shows its public half |
| `api/src/domain/peer/` | `peer-call.ts` signs one call to a peer and unwraps its envelope; `basecamp.ts` is `app.basecamp`, the dialer for Basecamp's `apps.preview` |
| `api/src/{domain,services,jobs,plugins}/` | the wing: atlas, claude, workbench and local domains; their services, jobs and the terminal plugin |
| `api/src/domain/laptop/` | fli's files on this machine, read through `@frontierjs/cli/core/{home,services}.js`: `laptop.ts` (Disk, Clear, Remove lane), `keys.ts` (secret files and their modes, the Frontier identity), `settings.ts` (global env masked, user commands), `running.ts` (dev servers and tree holds), `services.ts` (every service fli signs in to, its probe on request, the commands that use it). The `laptop` service is model-less and gated at ADMINISTRATOR, like `basecamps` |
| `web/src/routes/laptop/` | `/laptop/`: tabs Disk, Keys, Running, Services; `web/src/resources/Laptop.mesa` is its resource |
| `api/src/domain/servers/servers.ts` | The Servers screen (`FJS-D2006`–`FJS-D2008`): each `ProviderAccount`'s machines listed live through `@frontierjs/conduit-hetzner` / `conduit-digitalocean` (only `list` and `verify`, never create or destroy), one failing account erroring alone; `add` verifies the token before storing it. `services/servers/servers.service.ts` is its model-less service |
| `api/src/domain/local/local-ssh.ts` | `~/.ssh/config` Host aliases, resolved offline by `ssh -G`: the hosts shown beside the cloud machines. A copy of Basecamp's, not an import |
| `web/src/routes/servers/` | `/servers/`: machines grouped by account, the ssh hosts, fetched-at and Refresh, Add account and Remove; `web/src/resources/Server.mesa` is its resource |
| `web/src/routes/terminal/` | `/terminal/`: one shell in the home folder, outside any pin; `components/Terminal.mesa` with no `pin`, over `WS /ws/terminal` (`api/src/plugins/workbench-terminal.ts`), its tmux session the bare `workbench` |

| `web/src/routes/terminal/` | `/terminal/`: one shell in the home folder, outside any pin; `components/Terminal.mesa` with no `pin`, over `WS /ws/terminal` (`api/src/plugins/workbench-terminal.ts`), its tmux session the bare `workbench` |
| `api/config/junction.config.js` | port and CORS origins |
| `web/config/` | `sierra.config.js`, `vite.config.js` (5508, `strictPort`), `api-paths.js` (derived from `app.snapshot.md`) |
| `web/src/App.mesa` | the sign-in guard |
| `web/src/routes/_module.mesa` | the shell: topbar, nav, sign out |
| `web/src/routes/{index,login,workbench}/` | root redirect, the sign-in page, the empty state |
| `web/src/lib/{nav,session}.js` | the nav table; who is signed in |
| `desktop/` | the Tauri shell around `web/` (`wraps: 'web'`, `api` 5501): `config/desktop.config.js`, `deploy/build.mjs`, `shell/` (crate `workbench-desktop`, window `Workbench`, icon from `brand/assets/icons/`), `test/verify.mjs` + `probe.js` (sign in at the door, scan a fake `~/code`) |
| `config/api-origin.js` | turns `FRONTIER_PORT_BE` into the build's `FRONTIER_PUBLIC_API_URL`, read by `desktop.config.js` |
| `app.snapshot.md` | `junction app --app api/src/app.ts`; read by `web/config/api-paths.js` |
