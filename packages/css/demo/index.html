Reference

Not a screen
Everything else in this demo is a working screen.

This page is the exception: the two lineages below are not components you choose, so no realistic screen can demonstrate them without lying about what they are.

The two lineages

Surface — the block lineage

Every Card, Alert, Toast, Popover, Drawer and Dialog is a Surface underneath. Written bare it is a bounded box with no term of its own, which is the one case where reaching for it directly is right.

A Card
An Alert
Chip — the inline lineage

Every Button, Pill, Badge and Avatar is a Chip underneath — inline-flex centering, plus the machinery that derives a readable text colour from whatever fill a composite asks for. Chip is layout only: the bare form below takes a tone and stays transparent, because the skin lives in each composite's own file. That split is the point — the three after it request the fill and get the contrast for free.

bare chip a tone on a bare chip — still no fill Badge 7 DO

Prose

A region of authored copy. The package styles no bare paragraph anywhere else — it is not classless — so this is the scoped exception, and it only reaches inside a box that opted in by name.

  • Measure, so a paragraph and the list under it wrap at one column.
  • The muted ink body copy is set in.
  • List indentation, from the space ladder rather than a literal.

It sets nothing a term already owns, which is what lets it wrap a whole region without arguing with the components inside. The space between these blocks is the Stack's, not the Prose's.
