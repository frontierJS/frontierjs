---
title: register:atlas
description: The registers as one interactive page — what to work on, what to decide, what is open, settled and not started
examples:
  - fli register:atlas --open
  - fli register:atlas --out /tmp/registers.html
  - fli register:atlas --json
flags:
  json:
    type: boolean
    description: Print the model instead of writing the page
    defaultValue: false
  open:
    type: boolean
    description: Open the written page in a browser
    defaultValue: false
  out:
    char: o
    type: string
    description: Output path (default registers.html in the registers directory)
    defaultValue: ''
---

**Every register a project keeps, crossed on one page, for any project whose
`package.json` declares `registers`** — a client app's `.project/` as much as
this workspace's root. Six tabs: *Next* is the ranking `fli next` prints,
*Decide* is the queue `fli decisions` prints, then the open issues, the rulings,
the idea papers and the closed rows. Every record expands to its whole text, its
citations jump to the record they name, and every file link opens in the editor
at the line.

The page reads nothing of its own. The records come from the same readers
`register:check`, `next` and `decisions` use, so a row missing here is a row
missing from all four, and the fix is in the reader.

**A pick is still `fli decide`.** The page is a file and cannot write one, so a
question's options each carry a button that copies the exact command, with the
ruling section chosen on the page. `fli gui` is the page that writes.

**This is not a snapshot.** The ranking scores a row up when code it links was
touched in recent commits, so the page moves with git history alone. It carries
no `generated by:` line; regenerate it, never commit it.

<script>
import { spawn, spawnSync } from 'child_process'
import { writeFileSync } from 'fs'
import { dirname, relative } from 'path'

// Detached and ignored: an opener holding the pipe keeps the terminal after the
// command has finished, which reads as a hang.
const openInBrowser = (path) => {
  const cmd = process.platform === 'darwin' ? 'open'
            : process.platform === 'win32'  ? 'explorer'
            : 'xdg-open'
  try {
    spawn(cmd, [path], { stdio: 'ignore', detached: true }).unref()
    return true
  } catch {
    return false
  }
}

// A page written into a tracked directory shows up in the next `git status`,
// and a register directory is always tracked. Asked of git rather than guessed
// from `.gitignore`, which may be nested or global.
const ignored = (file) => {
  const r = spawnSync('git', ['check-ignore', '-q', file], { cwd: dirname(file) })
  return r.status === 0 ? true : r.status === 1 ? false : null
}
</script>

```js
const { findRegisterRoot, registerLayout } = await import(resolve(global.fliRoot, 'core/registers.js'))
const { collectRegisterAtlas, renderRegisterAtlas } = await import(resolve(global.fliRoot, 'core/register-atlas.js'))
const { styleBundle, ownStyleBundle } = await import(resolve(global.fliRoot, 'core/assets.js'))

// The nearest package.json declaring `registers`, so a run from inside a
// package or a surface means the project's registers.
const root = findRegisterRoot(process.cwd())
if (!root) {
  log.error('No package.json at or above here declares `registers` — add `"registers": { "prefix": "ABC", "dir": ".project" }` to the project root\'s package.json')
  process.exitCode = 1
  return
}

const outPath = flag.out ? resolve(flag.out) : resolve(registerLayout(root).dir, 'registers.html')
const model   = collectRegisterAtlas(root, { outDir: dirname(outPath) })

if (flag.json) {
  echo(JSON.stringify(model, null, 2))
  return
}

// The tree's own stylesheet where it has one, else the one this fli carries —
// a client app installs no @frontierjs/css, and a CDN link is an unstyled page
// on a train.
writeFileSync(outPath, renderRegisterAtlas(model, styleBundle(root) ?? ownStyleBundle()), 'utf8')

const open   = model.issues.filter(r => !r.closed)
const shown  = relative(process.cwd(), outPath) || outPath
const toPick = model.questions.filter(q => q.state === 'decidable').length

echo('')
echo(`  ✓  ${shown}`)
echo(`  ${open.length} open · ${model.ready.length} ready · ${model.blocked.length} blocked · ${toPick} to decide · ${model.rulings.length} ruling(s) · ${model.ideas.length} idea(s) · ${model.issues.length - open.length} closed`)
if (model.unparsed.length || model.duplicates.length)
  echo(`  ⚠  the registers disagree with themselves — run fli register:check`)
if (ignored(outPath) === false)
  echo(`  ⚠  ${shown} is not git-ignored — add it to .gitignore; it is regenerated, never committed`)
if (flag.open && !openInBrowser(outPath)) echo('  ⚠  could not open a browser — the file is written')
echo('')
```
