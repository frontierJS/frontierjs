# Build output and `@frontierjs/css`

The full entries behind this section of the `ui-hazards` skill's index.

- **Vite injects the built `<script>` at the first textual match for the body tag and does not skip comments.** A body tag mentioned inside a comment in a hand-written `index.html` receives the script: the build succeeds, `dist/index.html` looks right, and the page loads no JavaScript. Write the body tag only as the element itself.
- **A `var()` naming a token nothing defines drops the whole DECLARATION**, so a design system can be linked, matched and ignored line by line. An undefined custom property is invalid at computed-value time — `gap: var(--space-4)` is no `gap` property at all, and `border: 1px solid var(--border)` is no border. Nothing reports it: the stylesheet is in the bundle, every selector matches, and a browser drive asserts what a page SAYS (`FJS-545`). The ladder is **named, not numbered**: `3xs 2xs xs sm md lg xl 2xl 3xl 4xl 5xl 6xl`, each rung `calc(base × var(--density))`. `fli check`'s `css-token-undefined` is the guard, and it reads the table off the CSS the app installs. **A fallback is the opt-out and it means something** — `var(--knob, var(--color-primary))` is a knob a caller may set, and nothing is dropped.
- **A class name is not checked by anything**, and there is no guard: `.list` where the vocabulary says `.rows divided`, `.input` for `.field`, `.button` for `.btn`, `.stack-sm` for a rhythm the package does not ship. `@frontierjs/css`'s `vocabulary.json` is the list — the terms with their classes, plus `anatomy`, whose entry for a term carries the one canonical markup block. Read it rather than guessing; a class nothing defines is markup that looks styled and is not.
- **A code sample highlighted with `prefix: true` loses its first character.** `glow()` strips a leading `+`, `-` or `>` as a diff/callout marker, and all three are legal first characters in CSS (`> .child`, `+ .sibling`). `--` is disambiguated; the combinators cannot be, so **a CSS caller passes `prefix: false`**.
