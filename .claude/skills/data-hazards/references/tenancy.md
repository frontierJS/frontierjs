# Tenancy

The full entries behind this section of the `data-hazards` skill's index.

- **Under `strategy database` four seams belong to the tenant path rather than the single-client path.** A session is verified at the TRANSPORT, before any hook — so `IAuth.verifySession(token, from?)` carries the request's host and headers, without which an app whose people live per tenant can authenticate nobody (`FJS-487`). A raw route (`app.get`/`app.post`) runs inside the request scope, so `requestMeta()` works inside `/auth/login` and inside a webhook (`FJS-488`). `announceDataWrites` taps each TENANT's client on first open rather than one app-wide client (`FJS-489`). And the per-request principal resolver runs for an ANONYMOUS caller, exactly as `withLitestoneDb` does, since a claim is what a caller with no session carries — skipping it makes every guest basket a 404 (`FJS-490`). A `jsonl`/`logger` database stays schema-global and is written by every tenant's client, so its index is idempotent by primary key (`FJS-491`).
- **Tenancy is declared in the seed and there are two strategies.** `tenancy { }` at the top of `schema.lite` — `strategy database` is one SQLite file per tenant plus a registry that indexes them, `strategy row` is one database and a tenant column. Every reader asks one resolution (`db.$tenancy` / `registry.tenancy` / `resolveTenancy`), and precedence is **option → declaration → default**, so `litestone tenant create` and the running app agree on where a tenant lives (`FJS-D05`). **Row tenancy desugars into `@@deny`, never `@@allow`** — allows are OR'd within an operation, so an allow would widen every read to the whole tenant — plus a `@default(auth().<claim>)` stamp; two rules, because `checkCreatePolicy` runs BEFORE the stamp and an absent column is legitimate on create and belongs to nobody on read (`FJS-D05`). A model with no tenant column is reported by name at parse; `@@tenant(none)` says it spans tenants on purpose. `asSystem()` is the only way across, which is what a cross-tenant tier is built on. `packages/litestone/docs/multi-tenancy.md`.
